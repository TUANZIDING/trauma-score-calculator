# 创伤评分工具 v3 外部验证报告（2026-10-09）

## 结论
1. **实现正确**：TRISS 与 CRAN traumar 1.2.7 在 1000 组随机输入上最大差 2.2×10⁻¹⁶；ISS 重算与 TITCO 登记值一致 99.99%（13,602 例中 2 例不符），NISS 一致 99.98%。
2. **区分度与文献一致**：在三个公开国际数据集上复现了已发表 AUC。
3. **TRISS（MTOS 1995 系数）在 LMIC 人群严重低估死亡**：TITCO 预期 383 例死亡、实际 1,479 例，Z=−67.35，W=−14.09/100 例。在中国使用 Ps 须谨慎，需本地校准。
4. **危险分级 v3**：阈值依数据调整后，红色组死亡率 TITCO 46.2%、CRASH-2 25.8%、UVA 33.5%。

## 危险分级
v2 初版（SI≥1.0 为红）问题：CRASH-2 中 72% 判为红色；Ps 0.5–0.9 组死亡率 65.7%、≥65 岁且 ISS≥9 组 40.1% 却被归为橙色。
v3 调整：SI≥1.4 为红（Mutschler 2013 重度休克），1.0–<1.4 为橙，0.9–<1.0 为黄；Ps<0.9 与 ≥65 岁且 ISS≥9 升为红色。

## 局限
- 均非中国数据；TITCO 为中低收入国家人群，RR 缺失约 41%，完整病例分析可能有偏倚。
- CRASH-2 为出血试验人群，无 ISS，无法验证 TRISS。UVA 无生命体征和年龄。
- 数据中无插管、FAST、躯干穿透部位、抗凝史，相关分级条件未检验。
- TITCO 中黄色与绿色死亡率接近，分级下端区分力有限。
- 分级为工具设定，未经前瞻性验证；操作提示为指南要点提醒，不是医嘱。

### ICD-10 估算 ISS（ICDPIC-R 基础版 roc_max 映射，TITCO-I 13,292 例，排除烧伤）
- 映射覆盖：S/T 编码 52,047 个，未映射 6,157 个（11.8%，主要为 T00–T14 部位未特指、.7 多处损伤编码）。
- 与手工 AIS-ISS 一致性（TQIP / NIS 参考库）：Spearman 0.46 / 0.49；ICD 估算中位数偏高 4 / 11 分；差值 ≤8 的比例 73% / 41%；ISS≥16 一致性 κ 0.12 / 0.10。
- 区分度：ICD-ISS 0.631（0.620–0.642），ICD-NISS 0.658，手工 ISS 0.607，手工 NISS 0.637。
- 死亡概率 Pmort 严重低估：预期 841 例，实际 2,723 例，界面不显示。
- 结论：适合作“漏项/误判提示”，不能替代手工 AIS；默认 TQIP 参考库（偏差更小）。
