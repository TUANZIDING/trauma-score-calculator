<a id="use-cases"></a>

## Use cases

| What you need | How to start |
| --- | --- |
| Rapid severity read in the resus bay | Enter GCS, SBP, HR and age for GAP / MGAP / rSIG, shock index and a risk tier |
| ISS / TRISS for records or quality review | Enter AIS per injury from the AAAM manual; ISS, NISS, RTS and TRISS are computed with full working |
| Check manual AIS for missed injuries | Paste ICD-10 diagnosis codes for a rough ISS estimate and review flags (experimental) |
| Teaching and inter-rater training | Teaching mode: paired scoring, mini-lessons and practice cases |

<a id="quick-start"></a>

## Quick start

1. Open the **[web app](https://tuanziding.github.io/trauma-score-calculator/)**; on iPhone use Share → Add to Home Screen.
2. Offline: download [`index.html`](../index.html) and open it in Safari or Chrome. No install, no network.
3. Choose the AIS version, add injuries and vital signs; results update live and can be copied or printed to PDF.

<sub>Some in-app file previewers block scripts and leave the result area blank; open the file in a browser instead.</sub>

<a id="capabilities"></a>

## Capability status

| Status | Feature | Boundary |
| --- | --- | --- |
| Implemented · validated | ISS / NISS / RTS / TRISS / shock index | TRISS matches CRAN `traumar` to 2.2×10⁻¹⁶ |
| Implemented · validated (v3.2) | GAP / MGAP / rSIG | Validated on TITCO and CRASH-2; shown only, not used in tiering |
| Implemented · partly validated | Risk tiers and action prompts | Thresholds tested on three datasets; intubation, FAST and anticoagulant rules untested |
| Experimental (v3.2) | ICD-10-based ISS cross-check | Low agreement with manual AIS (Spearman 0.46); review flag only |
| Planned | Trauma Index, national QC export, batch W/M/Z | — |

<a id="validation"></a>

## External validation

In-hospital mortality AUC using the tool's own core; see the [validation report (Chinese)](../validation/validation_report.md).

| Dataset | Results |
| --- | --- |
| TITCO-I (India, 14,755) | TRISS 0.830, RTS 0.832, GAP 0.837, MGAP 0.831, rSIG 0.815 |
| CRASH-2 (40 countries, 20,207) | RTS 0.808, GAP 0.793, rSIG 0.789, MGAP 0.767 |
| UVA (USA, 18,680) | ISS 0.821, NISS 0.817 |

<sub>Calibration warning: MTOS coefficients badly underpredict deaths in TITCO (383 expected vs 1,479 observed). No Chinese data yet. Patient-level data are not redistributed.</sub>
